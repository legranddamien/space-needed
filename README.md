# Space Needed

Space Needed helps you find and reclaim disk space on your Mac. Review developer caches, build artifacts, temporary files, and other cleanup candidates, then choose exactly what to remove. Files go to the Trash by default where supported.

Requires **macOS 27 or later** and **Apple Silicon**.

[Visit the website](https://legranddamien.github.io/space-needed/). The first public download is coming soon.

This repository hosts the website, update feed, and downloadable app releases.
