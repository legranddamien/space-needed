围绕开发工具而设计

多种工具，一处整理。

找出开发环境留下的文件。可用的清理来源取决于已安装的工具和授予的访问权限。

⌘

Xcode 与模拟器

  • DerivedData
  • Xcode 归档
  • 设备支持文件
  • 文档缓存与旧下载
  • 设备与模拟器日志
  • 模拟器设备
  • 模拟器运行时

删除模拟器运行时需要可选的辅助工具。

{ }

Swift 与 Go

  • 项目 .build 文件夹
  • SwiftPM 缓存
  • Go 构建缓存
  • Go 模块缓存

缓存和构建文件可能需要重新生成或下载。

[ ]

Android 与 Gradle

  • Gradle 缓存
  • Gradle 分发包
  • 项目 build 与 .gradle 文件夹
  • 旧 Android Studio 日志
  • Android 虚拟设备

清理前请退出开发工具，并保留仍需使用的构建产物。

◇

容器与虚拟机

  • Docker 镜像、已停止的容器与构建缓存
  • 所选 Docker 卷
  • Tart 镜像

Docker 操作可能无法撤销。Colima 和 Docker 虚拟机的存储报告不属于应用中的可删除文件。

>_

软件包管理器

  • Homebrew 清理
  • 旧 RubyGems 版本

使用已安装工具自带的清理命令。

⊞

系统与应用

  • 所选临时文件
  • 不再使用的应用
  • 不需要的应用语言

删除应用语言需要辅助工具，且可能影响签名或更新。绝不会删除临时文件夹的根目录。
