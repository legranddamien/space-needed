  • Gradle caches
  • Gradle distributions

Containers & virtual machines

  • Docker images, stopped containers & build cache
  • Selected Docker volumes
  • Tart images

Package managers

  • Homebrew cleanup
  • Old RubyGems versions

System & apps

  • Selected temporary entries
  • Apple Music streaming cache
  • Unneeded app languages

Removing app languages requires the helper and may affect signatures or updates. Temporary roots are never deleted.
